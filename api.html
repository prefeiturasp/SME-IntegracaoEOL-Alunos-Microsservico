class apps.core.authentication.ApiKeyAuthentication[código-fonte]¶

Base: BaseAuthentication

Valida requisições via API Key.

authenticate(request)[código-fonte]¶

Autentica a requisição pelo header de API Key.

Parâmetros:

request – Requisição recebida pela view.

Retorna:

Par com o pseudo-usuário autenticado e credencial vazia, ou None quando o header não foi enviado.

Levanta:

PermissionDenied – Se a API Key recebida não for igual à configurada.

Parâmetros:

request (Request)

Tipo de retorno:

tuple[_ApiAuth, None] | None

Retorna o header de autenticação esperado.

Parâmetros:
